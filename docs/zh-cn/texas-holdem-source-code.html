产品功能

移动端德州扑克源码：C++与Tars推送、用户状态、房间上报、俱乐部请求、多玩法产品介绍和真实手机界面。

移动产品

资料面向 iOS、Android 与 H5，完整客户端工程需核对交付物。

多人状态

用户在线、游戏状态、房间地址和牌桌信息由服务模块管理。

多玩法方向

经典德州、奥马哈、短牌、大菠萝、AOF、SNG 和 MTT。

玩家与服务端流程

移动端登录进入大厅
选择俱乐部或牌桌
服务端记录在线与游戏状态
推送房间和牌桌更新
客户端展示对局结果

技术与源码模块

消息推送PushServant.tars、PushServantImp、PushServer
用户状态UserStateProto.tars、UserStateProcessor
俱乐部请求audit_club、change_club_balance、change_club_fund
房间状态房间用户、在线人数、牌桌信息和游戏地址上报
构建与配置makefile、道具/奖励/排行榜配置模型

公开仓库是有限代码快照；完整移动客户端、数据库、运营后台和玩法须以授权交付清单为准。
